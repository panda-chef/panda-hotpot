## 📝 摘要

这半年，我几乎天天在跟 AI 结对写代码。Claude Code 写到一半卡壳，我会习惯性地点开它那句"让我重新想想"，想看看它到底在纠结什么。

点开之后，要么是一串乱码，要么干脆写着"已隐藏"。

我试过各种旁敲侧击。让它"把刚才的思路完整复述一遍"，它给你一个规规矩矩的总结，但不是原话。让它"把你的内心独白写出来"，它就开始表演，跟它真实在想的东西，早就不是一回事。

最气人的一次，是我问它一道数学题错在哪，它给的解释头头是道，可我怎么都对不上它给的答案。那一刻我特别想知道，它脑子里到底算了什么。

我一直以为，那段思考被厂商锁在服务器深处，谁也碰不到。直到昨天，一篇论文把这事捅穿了。

论文标题很直白：Stealing Reasoning Traces from Proprietary LLM APIs。翻译过来就是，从闭源大模型的 API 里，把它的思考过程偷出来。

作者不是野路子。ELLIS 图宾根、马克斯·普朗克研究所、图宾根 AI 中心，还有安全公司 Snyk 的研究员。欧洲顶级实验室，走的是负责任的披露流程。

他们干的这件事，一句话能说完：只用了两次 API 调用，就把 OpenAI、Anthropic、Google 三家的隐藏思考，完整还原了出来。

在说他们怎么干的之前，我得先解释一件事：到底什么是"思考过程"。

大模型不是一口说出答案的。现在最好的模型，会先在内部打草稿——一步步推演，把问题拆开，试错，再给你一个干净的结论。

这份草稿，内行叫思维链。研究早就证明，逼模型"一步步想"，答案准确率高出一大截。

早几年的模型，你想让它想，它就把想的步骤原样打给你看。但 o1 之后，情况变了。

2024 年底 OpenAI 发布 o1，第一次把"先想再答"做成了产品。可从第一天起，它就只给你看一段"思考摘要"，真正的推理过程，一个字不放出来。
