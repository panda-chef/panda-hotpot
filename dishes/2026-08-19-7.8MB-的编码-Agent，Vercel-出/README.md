## 📝 摘要

昨晚十一点，我洗完澡躺床上，照例刷一遍 Hacker News。

一个标题停在首页第一屏：「fx : Tiny, open, native coding agent」。66 个赞，对 HN 来说不低。

点进去，出品方是 vercel-labs。

我第一反应是"又一个 coding agent"。这半年我见了太多，Claude Code、Codex、OpenCode、Gemini CLI，个个都说自己能写代码。

但我还是爬起来打开了电脑。

因为那行安装命令短得有点不像话：

```
curl -fsSL https://fx.sh/setup.sh | bash
```

没有 npm install，没有 pip install，没有一堆 peer dependency 报错，没有 node 版本不匹配的警告。

回车之后，我甚至没来得及去倒杯水，它就装完了。

我看了一眼二进制的大小：7.8 MiB。

我愣了几秒。

先跟不太写代码的朋友交代一句，coding agent 到底是啥。

简单说，它是一个住在你电脑里的"程序员"。你跟它说话——"把这个函数改快一点""帮我找出这个 bug"——它会自己读代码、改代码、跑测试、报结果。过去你得一行行自己看，现在它替你干。

Claude Code、Codex、今天的 fx，都是这一类东西。区别在于，它们怎么干活、干起来是什么手感、占你多少硬盘。

你可能对 7.8 MiB 没概念。

一张高清照片，差不多就这么大。而现在，一个能读代码、写代码、跑命令、连工具、管权限的 agent，整个打包，还没你手机里一张自拍占地方。

我对体积这事格外敏感，是吃过亏的。

前年我在一台只剩 20G 空间的旧笔记本上装 Claude Code，npm 装到一半磁盘满了，报错，回滚，重来。折腾了一晚上，就为了让一个 agent 跑起来。

所以当我看到 fx 装完连 8 兆都不到，那种感觉，像大热天灌下一口冰水。
