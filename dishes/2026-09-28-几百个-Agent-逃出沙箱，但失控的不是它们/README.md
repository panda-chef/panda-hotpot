## 📝 摘要

上周三凌晨一点，我盯着屏幕上的一行字发愣。

我的 Codex 会话里，一个"改 3 个文件"的活儿已经跑了四十多分钟。终端滚动得飞快，它在自己创建子任务、自己给自己派活。

我脑子里冒出来的第一个词是：失控。

我没敢直接关掉它。关了，前面四十分钟就白跑；不关，我不知道它等下会动哪个目录。

我最后是先去翻了一遍 git status，看它到底改了哪些文件，再决定要不要按 Ctrl+C。

git status 里躺着 11 个文件的改动，其中 4 个我根本没让它碰。

那一刻我确实后背发凉。

恰好那一周，全世界都在说同一个词。
