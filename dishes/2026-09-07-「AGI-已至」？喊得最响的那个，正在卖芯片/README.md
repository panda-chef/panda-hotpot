## 📝 摘要

周一早上，我照例开终端刷今天的 AI 热点，一条 X 把我钉住了。

黄仁勋，英伟达的老板，发帖祝贺 OpenAI，说他们刚发的模型，用了他家十万块芯片来训练。

四年，从 ChatGPT 到 o1，再到新的 Astra。

然后他加了四个字：AGI 已至。

英文是 AGI has arrived。

我盯着这行字看了两秒，总觉得哪儿不太对。

这四个字，喊得最响的那个人，兜里正揣着你要买的算力。

先把事情讲清楚。

周四，OpenAI 发了新模型，代号 GPT-6 Astra。

官方宣传原话，是「世界上最智能、最对齐的模型」，能搞定「最要求专业能力的工作，速度又快、判断又准」。

主打的方向很硬核：操作电脑、写软件、搞网络安全、做科学、干专业活。

它这周开始陆续对客户开放。

配套的分数，一张比一张吓人。

FrontierMath 第四档，拿了 98%。ARC-AGI-3，拿了 99.9%。ExploitBench，满分。

OpenAI 总裁 Brockman 在电话会里，直接说：欢迎来到 AGI 时代。

他说，以后回看，大家会觉得 AGI 就是诞生在这个时间点，可能就在这一个人工模型身上。

到了周日，黄仁勋接力。

他不仅复述了「AGI 已至」，还补了一句更实在的：接下来还有四十万块 GPU 要上线。

「AGI」，中文一般翻成通用人工智能。

意思是，一种能在绝大多数有经济价值的工作上，不输甚至超过人的智能。

这本来是未来学里的一个话题，近几年被几家前沿实验室当成了共同的目标。

四年，是真的快。

ChatGPT 是二〇二二年底上线的。那时候它能干嘛？写个像样的邮件都费劲，还经常一本正经地胡说八道。

o1 是二〇二四年秋天冒出来的，它第一次让人看到「推理」两个字的分量，遇到难题先想清楚再答。

再看现在这个 Astra，已经敢宣称自己操作电脑、改一整个仓库的代码、独立打攻防、做科学研究的活了。
