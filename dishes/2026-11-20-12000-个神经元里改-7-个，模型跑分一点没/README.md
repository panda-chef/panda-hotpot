## 📝 摘要

上周我为了省一笔 API 费用，在本地挂了个 8B 的开源模型。

下载过程顺得不像话。一个量化过的权重包，几十个 G，落盘，加载，回第一句话，速度比我想的快。

我做的检查就三件事：文件大小对不对、能不能正常对话、随手问两个问题看它会不会胡说。

三件全过。我把它挂进了自己的脚本，让它读目录、改文件、跑命令。

昨天看完微软那篇论文，我坐在椅子上想了很久。

我那三件检查，对这次这种攻击，一件都不管用。
