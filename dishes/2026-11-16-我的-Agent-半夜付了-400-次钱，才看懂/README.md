## 📝 摘要

上个月，我给一个每天自动跑任务的 Agent 接了个付费接口。

第三天早上看账单，一次任务被扣了 400 多次。

任务只成功跑完一次。剩下 400 多次全是超时重试——每重试一次，它就老老实实付一次钱。接口那边没做幂等，我这边也没有。

亏的钱不多。但那天我认真想了一个问题：让 AI 自己付钱，到底该谁负责？

结果就在 11 月 15 号，这件事被三家公司同时推到了台前。
