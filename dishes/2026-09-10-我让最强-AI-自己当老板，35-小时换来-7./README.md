# 🍲 我让最强 AI 自己当老板，35 小时换来 7.5 万行废代码

## 📝 摘要

我一直在折腾 agent 帮我写代码。Claude Code、Codex、我自己跑的那套 dev-loop，每天都要跟它们打交道。 我用的是 DeepSeek 的接口，成本便宜，干起活来也不含糊。可我发现一个规律：它越能干，我就越得盯着。 上周末我干了一件我一直想干、又一直不敢干的事：把缰绳彻底松开，让 agent 完全自己决定怎么写、怎么改、什么时候 commit，我只看它最后交出来的东西。 我想知道，最强的模型，到底敢不敢放手。
