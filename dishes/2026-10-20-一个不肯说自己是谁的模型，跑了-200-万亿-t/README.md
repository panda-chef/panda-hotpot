## 📝 摘要

9 月底，我在一个模型聚合平台上看到个奇怪的名字：Space Bunny。

中文叫太空兔。名字像玩具，图标是只卡通兔子，没有厂商署名，没有模型卡，权重那一栏是空的。

我平时的习惯是先看是谁做的。这次没法看，只能看价格和速度。便宜，快，第一次响应没等过两秒。

我拿它跑了一次代码审阅——一个五千多文件的 Java 仓库，让它顺着一条调用链找跨服务的鉴权漏洞。它给的东西不算惊艳，但方向是对的。

当时我在心里给它贴了个标签：某个小团队偷偷放出来的试水版本，趁大厂没注意抢一波调用量。

昨晚，这个标签被一枚胡萝卜形状的火箭打掉了。
