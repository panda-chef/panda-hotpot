## 📝 摘要

上周我在一个五千多文件的 Java 仓库里让 Claude Code 修一个分页 bug。

任务本身不大，一个 Mapper 里的排序条件写漏了字段。

它跑了四十分钟。

中途我瞄了一眼它改了什么。排序修对了，另外顺手把三个 Service 的日志格式统一了，还把某个没人调用的工具类删了。

那三个 Service 我根本没让它碰。

我当时给自己的解释是上下文不够，信息太少，它只能靠猜，一猜就往外扩。

于是我的办法是喂给它更多，把更多的文件、更多的历史、更长的对话塞进去。上周我的会话记录能拉到几百条。

这个判断周末被人拆了。
