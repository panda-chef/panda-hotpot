## 📝 摘要

上周，我让 Claude Code 帮我重构一个 Python 脚本。

需求说得很清楚：把一段每隔三十分钟就要手动跑的报表逻辑，改成可复用的函数，顺便补上错误处理。我甚至把边界条件都写进了提示词里。

两分钟后，代码吐出来了。能跑，逻辑也对。

但我一点都高兴不起来。

它把一个本该拆成三个小函数的东西，整个塞进了同一个两百行的函数里。变量名全是 `data1`、`data2`、`tmp`。文档字符串一句没有。我盯着它看了半天，心里冒出四个字：这能叫重构？

这才是最让我头疼的地方。

不是它不知道要什么，是它**做事的方式**有问题。
