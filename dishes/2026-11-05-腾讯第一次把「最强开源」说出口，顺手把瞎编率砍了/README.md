## 📝 摘要

上周我给一个 Java 项目改分页。需求写清楚，丢给 AI，它回来一段挺干净的结果。

我照着跑，报错。

翻出来看，它调用了一个方法。那个方法在当前这版依赖里根本不存在。名字起得特别合理，参数类型也对得上，就是没有。

它不是不会写，是不知道的时候不肯说不知道。

这种错最难查，因为看起来哪儿都对。

11 月 4 日中午，腾讯混元发了 Hy4 正式版。所有报道都在写同一句话：「首次跻身最强开源模型之列」。

我把发布材料和技术稿翻完，记下来的却是另外两个数字：15.76% 和 5.45%。

那是幻觉率。前者是 8 月的预览版，后者是这次正式版。
