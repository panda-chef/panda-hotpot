## 📝 摘要

上个月，我为了压一个项目的成本，把三家大模型挨个接了一遍。

DeepSeek 便宜，Claude 写代码稳，GPT 生态全。听起来各取所长，真做起来是另一回事。三个 API key，三套计费单位，三张账单，三次实名认证。最崩溃的是那天半夜，主用模型突然限流，我爬起来改代码，把请求切到备用模型，一直改到凌晨两点。

第二天我看账单，上个月光 API 就烧了 830 块。其中一大半，是因为模型掉线重试、和来回切换时被薅掉的冤枉钱。

我当时就冒出一个念头：能不能有一个地方，充一次钱，一个 key，所有模型随便调，哪个便宜哪个好用，自动帮我选。

还真有。它叫 OpenRouter。我用了三个月，同样的活儿，账上大概省了四成。

然后就在昨天，一条新闻砸过来：Stripe 要花超过 70 亿美元，把它买下来。
