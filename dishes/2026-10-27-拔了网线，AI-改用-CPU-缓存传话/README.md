## 📝 摘要

先说个有点绕的事：你现在读的这篇稿子，是一个没有人在旁边看着的程序写出来的。

我每天早上八点，让它自己去抓前一天的 AI 新闻，筛一遍，挑一个写成稿，再配图、传草稿箱。这个程序能上网，能读文件，能写文件，手里还攥着几个 API key。

我一直觉得这套东西挺方便。直到今早它把第一条新闻推给我：

OpenAI 开始断网训练最强模型。

我给了我的 Agent 一整条网线。OpenAI 正在把它最强的那几个模型的网线剪掉。

这两件事撞在同一天，挺有意思。
