## 📝 摘要

上个月我让 Agent 干过一件重复活：给一个老模块里四十多个接口补参数校验。

活不难，难的是等。

它每改一个文件，都要先生成一段思考，再吐一次工具调用，等结果回来，再决定下一步。四十多个文件，我盯着进度条从下午盯到天黑。

我后来把日志翻出来看了一遍，发现真正"想"的时间占比并不高。

大部分时间花在三个地方：等思考 token 一个个吐出来，等工具调用的返回，以及——最气人的——等它跑歪了之后重来一遍。

有一次它把两个文件的导入顺序搞反，编译报错，我只能从头再喂一遍上下文。那一次白等了七分钟。

这个体感所有用过 Agent 的人都有。也正因为这样，昨天有个模型发布让我多看了两眼。

因为它改的不是"想得更聪明"，是"写得快不快"。
