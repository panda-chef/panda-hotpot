## 📝 摘要

前天我干了一件挺没劲的事：给一个 agent 删记忆。

它有个记忆文件，攒了几个月，撑到上限了。我一条条翻，删掉三个月前的几条，剩下的压了两遍，才腾出位置。

删的时候我在想一件事：这东西每天帮我干活，可它对我这个人的了解，全压在几千字里。再往前的事，它就不记得了。

同一天晚上，一个开源项目在技术圈刷屏。前 DeepSeek 的人做的个人 Agent，跑在你自己电脑上，每天晚上把邮件、日历、会议整理成知识库，长期记忆准确率做到 95%。

我打开它的 GitHub 看了一晚上。下面是我的笔记。
