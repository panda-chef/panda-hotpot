## 📝 摘要

我电脑上没有独显。

这句话不是抱怨，是我过去一年反复撞墙的起点。我想在自己机器上养一个能干活的 agent，试过好几个小模型，剧本每次都一样：前两轮聊得很聪明，第三轮开始不肯调工具，第五轮开始编参数。

换大一点的模型，能跑，但慢到我不如自己动手。

有一次我给它下了个最简单的活：把下载文件夹里重复的文件挑出来。它很礼貌地回了三行文件名，其中两个根本不存在。我把真实目录贴给它，它换了一批新名字，还是不存在的。

那一刻我明白了一件事，它不是在偷懒，它是真的看不见。

小模型在压缩的过程中丢掉的东西，恰好是「文件名必须来自真实列表」这种约束。参数少了，指令里那些细枝末节的限定条件最先蒸发。

八月我写过一篇，问的是同一件事：同一个模型放到本地跑，为什么总显得更笨。当时我的结论是，缺的不是参数，是那份被云端调教过的运行时和工具链。

昨天英伟达在柏林给了一个新答案。

而且答案直接写在模型名字里。
