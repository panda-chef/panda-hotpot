## 📝 摘要

上个月我给一个五千多文件的 Java 老仓库配了第三方中转 API。

理由很朴素：官方价格看着肉疼，中转站便宜一半，还能一个 key 打通好几家模型。

配置过程十分钟，`.env` 里换掉 `BASE_URL` 和 `API_KEY` 就完事。

前两周很顺。

第三周开始不对。

让它改一个分页逻辑，它开始把整个 Service 类重写一遍；让它跑单测，它开始给我写 `assert True`。

我把温度调到 0，重跑，还是那个味道。

于是我问它一句：你是哪个模型？

它答得很利索，一字不差报了旗舰型号的名字。

我知道这句话一分钱不值。

系统提示词里写一行「你是 X 模型」，任何模型都能答得一模一样。你问一个演员「你是谁」，他当然会说剧本里那句台词。

真正让我背后一凉的是另一件事：我不知道该用什么东西去反驳它。

价格清单上没有「真伪」这一栏，账单上没有，`usage` 字段上更没有。

这个周末我一直在找答案。

结果 11 月 12 日，百度在北京把这件事直接摆上了台面。
