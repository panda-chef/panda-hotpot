## 📝 摘要

我有个不太像开发者的习惯：每次给流水线换模型，先去翻它的许可证。

不是先看价格，是先看许可证。价格改一行配置就换了，许可证改不了。

这周三我照例去翻，翻到一个挺拧巴的组合。

一个新的编程模型，成绩很好，价格很便宜。它的底座是一个 Apache 2.0 的开源模型，任何人都能从 Hugging Face 下下来。成品呢，权重锁死，不公开。

我盯着那两行看了半分钟。

这不算违规，一点毛病没有。但它是这两年我见过最干净的一次「开源怎么被吃掉」的样本。
