## 📝 摘要

昨晚十一点，我让 AI 在 hse-server 里改一个 Mapper。

它张口就写了个 `var ids = ...`。

我在项目根目录那份说明书的头一行写着：Java 8，禁止 Java 9+ 语法。

我盯着屏幕看了十秒，起身去翻目录。

问题不在它身上，在我身上。

这事不是第一次了。上个月我让它写一个批量导出的接口，代码看着挺漂亮，提交上去被人打回来，理由是用了 Java 11 才有的 API。我当时还怪它不听指挥。

回去问它为什么不看规则，它说它没看到那份规则。

那句话我当时没往心里去。现在回头看，它说的是实话。
