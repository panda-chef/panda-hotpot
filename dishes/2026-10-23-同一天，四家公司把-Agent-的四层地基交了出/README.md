## 📝 摘要

上周我干了件挺蠢的事。

我想把一个自己写的技能包，从平时用的编程 CLI，搬到另一个 Agent 工具里。文件夹原样拷过去，`SKILL.md` 一个字没改，我以为完事了。

结果新工具打开以后，答得驴头不对马嘴——它把我技能里那段「什么时候该用我」的开场说明，当成正文内容，逐句复述给我听。

我盯着屏幕想了半分钟才明白：格式一样，解释权不一样。

那天我把那个文件打开，从头改到尾。加了一段「使用时机」，又补了三条否定条件——什么情况下不该用这个技能。改完拷过去，终于正常了。

但这意味着，同一个技能，我维护了两份。

一份给这个工具，一份给那个工具。以后改一处，得记得改两处。这种重复劳动我在项目里躲了十年，结果在 Agent 这儿又撞上了。

昨天这件事有了个新答案。
