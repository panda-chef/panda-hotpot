## 📝 摘要

昨晚十一点多，我在一个五千多文件的 Java 仓库里，等一个 AI 修分页 bug。

修完我顺手算了笔账。按这个仓库日常的用量，一个月大概几千万到上亿 token 的进出，照公开报价折成人民币，一年几千到一万多。

钱不多。但我盯着这个数字想了一件事：这些 token 现在是租的。如果它们跑在我自己桌上的一台机器上，会怎么样。

第二天早上，Meta 给了半个答案。

顺便说一句背景。过去两年，开放权重这个市场一直是国内在推着走。

阿里的 Qwen、月之暗面的 Kimi K3、智谱的 GLM，长期被当成全球开放权重的第一梯队。Meta 这次发布时自己也承认这一点，说新模型“在某些方面甚至可以和它们匹敌”。这句话的措辞本身就说明了很多。

所以今天这批模型，实际上是在跟国内已经在跑的东西比。我连着看了一周的发布，感觉是两边的节奏都变快了。
