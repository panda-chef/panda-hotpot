## 📝 摘要

今天早上八点，我打开电脑，干的第一件事不是看新闻。

是给自己做体检。

上个月我写了个小脚本，专门扫本地那些喂给 AI 的常驻文件——AGENTS.md、CLAUDE.md，还有一堆 SKILL.md。它今天吐出来一个数：125 个技能文件，正文加起来 121 万字符。

121 万字符。我盯着这个数看了几秒。

写这脚本的起因很小。上个月有一次，我让 Claude Code 改一个模块，改到一半它忽然开始"压缩上下文"，我前面交代的三个约束从它记忆里掉了出去。等我发现的时候，它已经把不该动的那部分重构了。

那天之后我想知道一件事：每轮对话里，那些跟当前任务无关的说明，到底占了多少。

然后我想起上周随手存进待读清单的一篇博客。9 月 11 日发的，作者是 OpenAI Codex 团队的 Eric Provencher，标题叫《Rethinking skills and prompts for GPT-6 Astra》。

翻过来就是：重新想想你给 AI 写的那些技能和提示词。

全篇的意思可以压成一句话：过去一年你为了伺候弱模型攒下的说明书，现在正在拖累强模型。
