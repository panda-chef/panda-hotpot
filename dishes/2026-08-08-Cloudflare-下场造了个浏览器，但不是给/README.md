# 🍲 Cloudflare 下场造了个浏览器，但不是给你用的

> 菜品编号：2026-08-08-Cloudflare-下场造了个
> 📢 公众号：硅基饲料 · 🗓️ 发布：2026-08-08 · 状态：✅ 已发布

## 📝 摘要

上周我在写一个自动化脚本。 让 AI agent 帮我爬几个网页，填个表单，截个图存下来。听起来挺简单的事，对吧？ 结果折腾了整整一个下午。 问题出在浏览器上。我用的 Hermes Agent 每次打开 Chromium 都要吃掉 500MB 内存，三个 tab 一开，风扇就开始尖叫。最离谱的是，agent 根本不需要标签页、书签栏、主题皮肤这些东西。它就想要 HTML 文本和截图。
