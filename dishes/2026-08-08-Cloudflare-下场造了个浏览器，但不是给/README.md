## 📝 摘要

上周我在写一个自动化脚本。

让 AI agent 帮我爬几个网页，填个表单，截个图存下来。听起来挺简单的事，对吧？

结果折腾了整整一个下午。

问题出在浏览器上。我用的 Hermes Agent 每次打开 Chromium 都要吃掉 500MB 内存，三个 tab 一开，风扇就开始尖叫。最离谱的是，agent 根本不需要标签页、书签栏、主题皮肤这些东西。它就想要 HTML 文本和截图。

我盯着任务管理器里那个臃肿的 Chromium 进程，忽然觉得自己像个用挖掘机种花的傻子。

工具不对。
