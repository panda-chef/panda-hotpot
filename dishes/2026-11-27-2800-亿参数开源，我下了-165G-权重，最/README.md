## 📝 摘要

上上周，我在公司一个 Java 项目里干一件很枯燥的活：把两千多张老报表的字段名，对齐到新系统的字典上。

这活没什么技术含量，就是看、比、改。

老系统里同一个东西有三四个叫法，金额单位有的按分有的按元，日期有的存字符串有的存时间戳。

我把它丢给模型批处理，一天能过三百张，感觉自己像个包工头。

干到第四天，账单让我停下来了。

不是贵得离谱，是每一张表都要重读、每一个字段都要来回确认，token 花得比我预估的快三倍。

那笔钱不多，但它让我意识到一件事：这段活我可能要连干两个月。

两个月按这个烧法，不如自己弄台机器跑。

11 月 24 日，百度把文心 5.5 Flash Preview 的权重放出来了。Hugging Face 和魔搭都能下，Apache 2.0。

我当天下载，第二天下午跑通，第三天把它从流水线里撤了。

先别急着说我翻车。撤掉的是它最不擅长的那一环，留下来的是它真正强的地方。

这件事值得写，因为它把一件很虚的事讲实了：一个模型"强不强"和你"该不该用"，从来是两个问题。
