## 📝 摘要

我电脑里长期装着两个 JavaScript 运行时。

Node 那个从 2019 年用到现在，项目里到处都是它的影子。Deno 那个是 2021 年装的，装完跑过一个抓取脚本，之后再没打开过。

不是它不好。是我懒，也是生态在那里摆着。

我记得当时是被它的权限设计说服的。默认什么都不给，要读文件得写 --allow-read，要联网得写 --allow-net。第一次运行的时候弹出一串拒绝提示，我还愣了一下——原来一个脚本能不能碰我的硬盘，是可以先问一句的。

那个设计我到现在都认为是好设计。但它没能把我留下来。

今天早上刷热榜，一条新闻挂在第一，一千多分，五百多条评论：Cloudflare 收购了 Deno。

我打开自己那个 Deno 目录看了一眼。它的创造者刚刚宣布，一年之后，它不再更新了。
