## 📝 摘要

周四晚上我在整理硬盘。

D 盘翻出来十一份 AI Agent 的配置。有写成 AGENTS.md 塞在项目根目录的，有藏在 .claude 子目录里的，更多的是我随手记在便签上、只有我自己看得懂的几段提示词。

起因是同事昨天问我要其中一份。

我复制粘贴发过去。他照着建了目录、装了依赖，半小时后回我一句：

「怎么跑不起来。」

缺工具，缺模型，还缺一个我自己都忘了的参数。

这不是他的问题。

我给出去的东西，其实只是我这台机器上半小时前刚好跑通的一个状态。它能跑，靠的是我这个目录里恰好装过的依赖、恰好写过的环境变量、恰好还留在会话里的上下文。

换个壳子，它就死了。

同一天晚上我刷 Hacker News，看到一个东西挂在首页上。

Docker 官方开源的 docker-agent，将近 300 分。

我前后花了两个晚上把它摸了一遍。装、跑、拆配置、打包。

下面是完整记录，包括踩的坑。
