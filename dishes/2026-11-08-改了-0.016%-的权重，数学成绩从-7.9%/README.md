## 📝 摘要

我有个改不掉的习惯：模型一犯错，我就去改提示词。

上个月在一个五千多文件的 Java 仓库里，它把一个分页参数写反了。我在系统提示词里加了一条规则，它好了。

第二天它换个地方又写反，我加第二条。

到第三天，那个提示词文件里有四十多行，专门讲分页。它开始在新的场景里绕回去。

我当时想的还是「再加一条」。后来才反应过来，我一直在跟一个我看不见的东西谈判。

11 月 2 日，MIT CSAIL 的四位研究者发了一篇博客，叫《Sparks of Weight-Space Programming》。

他们做的事很简单：不问模型「你为什么错」，而是把它脑子里的那串浮点数直接递过去，让它自己看。

这篇博客发出来之后，隔了两三天才在中文圈炸开。我读了两遍原文，又去找了两篇挑刺的复现，才敢写。

值得写的原因不是那些成绩，是它把一个一直没人动过的假设摆到了桌面上：权重是可以被「写」的。
