## 📝 摘要

我电脑的窗口列表常年是满的。

Claude Code 一个、Codex 一个、OpenCode 一个，还有一个自己攒的壳。每个后面挂着不同的模型，每个都有一套自己的快捷键。

我一直有个模糊的信念：换个壳等于升级。壳做得好，模型就跟着聪明。所以我换得很勤，看到谁家出了新的终端 Agent，第一反应是装一个试试。

上周我看到一份评测，把 21 组壳塞进同一个考场。看完之后，我把自己一直相信的那件事划掉了。

我一直在为一个只占 2.3% 的东西付钱。
