## 📝 摘要

上周我给一个排查任务同时开了两个 Agent。

一个翻日志，一个读代码。我当时想的很简单：这不就是双核吗，快的那个先出结果。

四十分钟后我回来，两个都交了补丁。

git 里躺着三条提交，后两条互相抵消。第一个改的那行，被第二个改了回去，还贴心地加了注释，说明为什么「不该这么改」。

我花了半小时手工合并。合完发现真正的问题在第三处，两个都没碰到。

那天的结论是：模型还是不够聪明。

昨晚看完 Anthropic 的公告，我把结论改了。问题不在它们，在我——我给了它们两个人同一个目录、同一张纸、两支笔。
