## 📝 摘要

上周我给自己的小助手加联网搜索。

不是调个库那么轻松。我得先想清楚模型怎么判断"这次该不该搜"，再写个函数去抓页面，再处理抓不到的情况，最后把结果拼回上下文，还得给每段资料编号——这样回答里的 [3] 才能对回原文。

一下午。

抓取成功率七成左右。剩下三成是各种别扭：有的站点认 UA，有的直接返一堵墙，有的正文全塞在脚本里。我最后的兜底是"抓不到就跳过"，然后祈祷模型别引用那个被跳过的链接。

十一月十三号，DeepSeek 在 API 变更日志里发了条更新，标题很朴素：Releasing the full suite of application APIs。

读完我的第一反应是，那个一下午，白干了。
