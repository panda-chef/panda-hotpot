## 📝 摘要

今天早上八点半，我让 Agent 帮我跑一条统计命令。

它没跑。

屏幕上弹回来一行字：BLOCKED。理由是「无人值守会话不允许执行这类命令」。

拦住它的不是运维，也不是杀毒软件。

是我自己设的那层闸门。

规则很简单：没有人盯着的时候，凡是执行脚本、改系统配置这类动作，先拦下来再说。

我当时有点不爽。改个配置的事，又耽误十分钟。

半小时后我翻到 Anthropic 昨晚深夜发的那份报告，忽然觉得那十分钟拦得挺值。
