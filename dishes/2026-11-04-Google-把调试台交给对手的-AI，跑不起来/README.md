## 📝 摘要

上周二我干了一件现在想起来有点后怕的事。

一个接口要改返回结构，我把需求写成三段话丢给 Agent，它改完，编译通过，单测全绿。我看了一眼 diff，逻辑清楚，字段也加对了，就合了。

第二天早上前端同学发来一张截图：页面一片空白。

我把日志翻出来，问题出在 SQL 那层。真实数据库返回的列名，跟我单测里 mock 的那份数据对不上，Agent 照着我 mock 的数据写了映射。

编译过了，测试过了，就是跑不起来。

这件事之后我想了很久。Agent 写代码，早就不是「写得出来写不出来」的问题了。它真正的软肋在另一头：它改完的那一下，没有人让它真的跑一遍。

11 月这几天，Google 在 Android Dev Summit 上给了一套答案。答案不是更强的模型，是把「跑一遍」这件事，塞进了终端。
