## 📝 摘要

上周我给一个 Java 项目挑模型。

同一份代码、同一套提示词、同一批任务，让三个模型各跑一遍。分数差得离谱。回头去对厂商的排行榜，同一批模型的名次又能换来换去。

我盯着两张表看了半小时，最后承认一件事：我手里根本没有尺子。谁的榜，谁说了算。

更麻烦的是，这两张表连量纲都不一样。一张按任务通过率排，一张按每次任务的成本排。我把它们并排放进同一个 Excel，看着像在比较，其实什么也没比出来。

昨天看到一条消息，这事算是有了一点眉目。

11 月 22 日，OpenAI 首席科学家 Jakub Pachocki 在官网发了一篇博客，标题很短，叫《Perplexity and Intelligence》。文章做了一件很少见的事：把公司内部从 GPT-3.5 到 GPT-6.2 Astra 的预训练困惑度数据，摊到纸面上。

奥特曼当天在 X 上转了一句：这是 OpenAI 一段时间以来发布的最重要的内容。

我先去看的那几个数字。
