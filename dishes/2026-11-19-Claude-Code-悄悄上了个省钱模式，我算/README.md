## 📝 摘要

上周五晚上十一点，我盯着终端右下角那个一直往上跳的 token 计数发呆。

活不难。一个五千多文件的 Java 仓库，改掉一个分页查询的边界条件，再补两条单元测试。Claude Code 前后改了四轮，每一轮都把我前面几轮读过的文件重新过一遍。

活干完了，账单也上去了。

事后我把那四轮的用量翻出来看，输出没多少，输入占了大头，重复读进来的文件内容一层层叠着。

这也是我开始盯 token 结构的原因。模型的账不是按"你想了多久"收的，是按"你让它看了多少遍"收的。

第二天翻更新日志我才知道，Claude Code 在这个月 12 号的 v2.1.323 版本里，塞进了一个叫 Code Mode 的实验功能，默认关着。官方很克制，文档里没给任何节省幅度，只说能少一些往返。

这不像一次普通更新。它改的是 Agent 花钱的方式。
