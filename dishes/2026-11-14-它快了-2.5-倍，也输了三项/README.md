## 📝 摘要

上周三下午，我在一个五千多文件的老 Java 项目里，让 AI 改一段分页逻辑。

改本身只用了几十秒。

真正花时间的是等。旗舰模型每走一步都要想很久，一个十几步的任务，我泡了杯茶回来，它还在读第五个文件。

那天晚上我给自己定了个规矩：规划用贵的，执行用便宜的。

第二天效率大概好了三成。代价是我得手动切模型，一个任务切两三次，忘一次就白省。

然后昨天，Google 把我这套手动规矩，做成了一个开关。
