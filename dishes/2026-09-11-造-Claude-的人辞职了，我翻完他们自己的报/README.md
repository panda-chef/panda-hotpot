## 📝 摘要

昨晚十一点，我在终端里等一个重构任务跑完，等的时候照例刷 HN。

刷到一条标题：两名 AI 研究员从 Anthropic 和 Google 离职。

我点进去了。第一句引语就把我看愣了——「房间里没有大人」。

我每天都用 Claude Code 写代码，用它的接口干活，每个月老老实实付钱。所以我理所当然地想知道：造这东西的人，究竟在怕什么。

我每天交给它的是什么？公司仓库里的代码、客户的名字、合同里的条款、我自己写给自己的备忘。我用它的时候，这些东西会经过某个机房。

以前我不太想这件事。

今天这条新闻让我想了一下：我该担心什么？天塌这种事我管不了。我能管的是那些具体的、明天就可能发生的事。

先给结论。这条新闻我建议你认真读，但原因跟"AI 要灭世"没关系。是因为三组数字。
