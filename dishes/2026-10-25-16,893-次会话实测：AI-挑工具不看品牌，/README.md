## 📝 摘要

上周我给本机一个编程助手派了个小活：给已有项目补一个发邮件的功能。

它没直接写代码。

它先翻了项目里的依赖清单，看同目录的另一个模块用了哪个 HTTP 客户端，又打开两个我压根没听过的邮件服务商文档，读了三分多钟，最后选了一个技术群里从没人提过的名字。

我盯着那段日志看了半天。

它没问价格，没看官网首页的客户 logo 墙，也没打开那家的中文站。它读了三分钟文档，就下单了。

昨天我看到一份研究，发现我上周看到的不是个例。

有人把这件事做成了实验：让三个编程智能体在 75 个真实代码仓库里挑第三方服务，还得真装进去、真跑通，一共跑了 16,893 次会话。

结论有点扎心。二十年的品牌建设，在它们的眼里不如一个 lockfile 好使。
