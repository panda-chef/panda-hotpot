今天早上打开终端，习惯性地跑了一下 `claude --version`。

2.1.220。

我随手 `npm update -g @anthropic-ai/claude-code`。几秒钟之后，再跑一次——2.1.221。

我本来没当回事。Claude Code 的更新很快，一周一两个版本是常态。但我在 changelog 里看到一行字，停住了。

"Added Focus view: a chat-menu toggle that hides tool activity behind an expandable per-turn summary."

翻译成人话：你现在可以一键隐藏 AI 工作时那堆刷屏的工具调用了。

我试了一下。然后我就知道，这篇文章必须写。
