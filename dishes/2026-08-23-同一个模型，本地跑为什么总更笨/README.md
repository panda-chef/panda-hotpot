## 📝 摘要

上周我把一个 Qwen 模型下到了本地。

事情是这样的。我最近迷上了在迷你主机上跑本地模型，想把一个能写代码、能查资料的助手塞进一台巴掌大的机器里，不用联网，不用交 API 费，开机就能用。这个念头，从我看完那篇"14MB 模型跑树莓派"的文章起，就一直在挠我。

于是我动手了。找到模型页面，把 GGUF 文件拖下来，四五个 G 的下载进度条走了大半天。下之前，评论区清一色在喊"这模型牛炸了"。我信心满满地敲下第一行提示词。

然后我对着终端沉默了十分钟。

同一个模型，同一份权重文件，云端里那个聪明、听话、写代码行云流水的它，到我手里，像是换了个人。问它一个简单的问题，它答得前言不搭后语。让它写段代码，它写到一半开始鬼打墙。最离谱的一次，它陷在"思考"里出不来，光标闪了五分钟，一个字没吐。

我一直以为是自己的显卡太烂。直到读完 Level1Techs 论坛上一篇 158 人收藏的帖子，我才发现，我错了。问题根本不在显卡，在我整套"跑模型的方式"。
