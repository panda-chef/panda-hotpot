## 📝 摘要

上周我在一个五千多文件的 Java 仓库里，让 Agent 改一处跨模块的接口。

第一轮很漂亮。它找到调用点，改了签名，编译过了。

第二轮我让它顺手把测试补上，它开始加戏：把三个不相关的 service 一起重构了，六个测试挂掉。

我回滚，把需求写得更死，再跑。

这次它老实了。可换到下一个模块，同样的毛病又冒出来。

那天晚上我盯着屏幕想了一件事：为什么同一个坑，它能踩三次，而且每次踩得一模一样。

昨天翻美团龙猫团队的技术报告，我找到了一个说得通的答案。

不是模型不聪明。是没人把它摔跤的姿势拍下来，反复放给它看。
