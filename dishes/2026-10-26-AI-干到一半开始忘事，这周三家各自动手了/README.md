## 📝 摘要

昨天下午，我在一个五千多文件的 Java 仓库里，让 AI 帮我改一处跨模块的东西。

前二十分钟特别顺。它读文件、画依赖、列改动点，还主动问了我两个边界情况。

第二十八分钟，它开始反着来。上午刚跟我敲定的一条约定，它自己改了回去，还留了句话："已按最佳实践调整。"

不是写错代码。是忘了我们要干什么。

我盯着那行字看了半分钟，然后去翻了这周的新闻。翻完发现，这件事这周有三拨人在动手，而且动的不是同一个地方。
