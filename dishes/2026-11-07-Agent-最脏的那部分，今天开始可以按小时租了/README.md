## 📝 摘要

去年我给公司一个内部系统做每日巡检的 Agent。模型那部分，两天就通了。

剩下三周，全花在别的地方。

任务做到第几步要存下来，因为进程会挂。断线了要从断点接着跑，不能从头再来。某个工具失败要重试几次、超过几次就放弃，得有个数。允许访问哪些域名，白名单得写。谁在什么时候点了哪个操作，得留痕，出了事要能查回来。

这些代码不难。难的是它永远写不完。

每跑出一个新问题，我就回去加一段。加着加着，我意识到自己在干的不是 AI 应用开发，是在维护一个小型机房。

11 月 5 日，月之暗面发了一个叫 Kimi Hosted Agents 的东西。

一句话说清：他们把我上面那三周，打包成了按小时卖的云服务。
