## 📝 摘要

凌晨三点二十，我在跑一个批量改文件的小脚本，等它跑完就睡。

手机连着弹了两条。

一条：OpenAI 发布 GPT-6 Sol 和 GPT-6 Luna，API 价格比上一代促销价砍一半。

另一条：Anthropic 发布 Claude Opus 5.5，典型负载成本比 Opus 5 低四成。

同一天，两家，都降价。

我本来准备睡了。翻到 Opus 5.5 的价格表里有一行「缓存命中 0.20 美元 / 百万 token」，我把手机放下，起来打开了电脑。

因为这一行跟我每天干的事直接相关。
