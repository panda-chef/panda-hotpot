## 📝 摘要

上周我在这号写过一篇，讲我的 Codex 会话自作主张改了 11 个文件，其中 4 个我根本没让它碰。

那篇发出去之后，收到最多的一句话是：有没有办法提前拦住它。

我给不出好答案。

当时我能说的只有事后看 git status、给它单独开个目录、prompt 里多写几遍别动别的文件。这些办法你自己也知道，靠的是它听话。

这周一早上八点多，我坐在电脑前刷 HN，看到一条 153 分的帖子，标题就一行：

Mxc: Microsoft Execution Containers version 1.0.0

我得承认，点进去之前我是有点疲惫的。

这两年「给 agent 加安全」这个说法听太多了。几乎每个套壳产品都会在官网第一屏写一句安全可控，点开一看，是一个确认弹窗。

但我还是点进去了。

点进去之后，我在那个仓库里待到中午。中间只起来接了一次水。
