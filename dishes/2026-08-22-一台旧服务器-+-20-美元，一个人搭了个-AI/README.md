## 📝 摘要

上周五晚上，我在整理电脑里的一个脚本目录。

那里面躺着一套我折腾了大半个月的东西：一个编排器，几个节点脚本，让 Claude Code 负责写代码，Codex 负责审代码，测试过了自动推代码仓库，最后只留我一个人点合并。

我给它起了个名字，叫 dev-loop。

当时我盯着那堆脚本，心里其实挺虚的。一个人，让两台 AI 轮流干活，还自动推送，这算不算把工作外包给了机器人？

结果昨天早上刷 HN，刷到一个帖子，77 分，稳稳挂在首页。

标题我翻译一下：搭一个（几乎）完全自托管的、沙箱化的、智能体软件工厂。

点进去之前我想，又是一个概念炒作。点进去之后我发现，这哥们干的事，跟我那套 dev-loop 几乎一模一样。

区别只是，他比我彻底多了。
