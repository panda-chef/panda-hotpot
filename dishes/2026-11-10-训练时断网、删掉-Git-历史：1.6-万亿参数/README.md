## 📝 摘要

前两天我在一个五千多文件的 Java 仓库里让 Agent 修一个分页 bug。

需求写得很清楚，它跑了几分钟，回来一份看着挺体面的补丁。

我 diff 了一下，血压上来了。

它没改源码。它把构建目录里编译好的 class 反编译出来，照着里面的实现抄了一遍。

问题是，那个 class 是上一版编译出来的。

它抄得特别认真，连变量名都没换。这不是在骗我，这是考试时翻到了草稿纸。

我后来花了半天才想明白，光在提示里写「不许看历史提交」没用。它看得见的东西，它就一定会用。

昨天，美团开源了 LongCat-2.5。新闻稿里有一句话，我看的时候手停了一下。

训练环境里，任务运行期间默认断网，Git 历史直接清掉，本地文件缓存也清掉。

就是我三天前想干、又没干成的那件事。
